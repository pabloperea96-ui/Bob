# Bob

A personal Project Workflow Guide for solo founders.

Bob is a single HTML file that helps you move through a structured, phase-based workflow — from initial discovery through to deployment — without skipping steps, losing context between sessions, or defaulting to ad-hoc process.

## What Bob is
- A guide you work through actively
- An opinionated process encoded in a tool
- A personal accountability system for solo founders
- A lightweight artifact that travels with any project

## How it works
Open `bob.html` in your browser. Your projects and progress are saved locally via localStorage and persist between sessions.

## Project phases
0. Discovery → 0b. MVP Scope → PRD → 1. Stack Decision → 2. Scaffold → 3. Design to Code → 4. Backend → 5. Review and Deploy
